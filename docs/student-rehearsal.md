# 학생 화면 리허설 개선 — 2026-10-05

## 확인한 문제

- 기존 미리보기는 실제 수업의 현재 단계에 종속되어 자체적인 다음 단계 이동을 제공하지 않았다. 타이머를 기다려도 자동 전환되지 않았다.
- 예시 팀이 고정되어 미리보기의 입력과 역할 공개는 실제로 반영되지 않았고, 발표에서 성찰로 이동하는 버튼도 동작하지 않았다.
- 최대 512px의 모달에 태블릿용 학생 화면을 넣어 컴퓨터에서도 선택지·카드가 좁아지고 줄바꿈이 과해졌다.

## 개선

- 실제 수업과 독립적인 단계 상태, 직접 단계 선택·이전·다음·성찰 이동을 제공한다.
- 실제 학생 화면을 그대로 재사용하되 팀 쓰기 작업을 리허설 안의 로컬 상태로 처리한다. 실제 Firebase 쓰기 차단도 유지한다.
- 정책·역할·입력은 단계와 화면 폭을 바꿔도 유지한다. 처음부터 다시 할 때는 이전 리허설의 지연 저장이 새 입력을 덮어쓰지 않도록 한다.
- 기본 PC 모달은 최대 1152px이며 전체 화면으로 확대할 수 있다. PC 보기의 뉴스 카드와 정책 글씨를 확대한다. 태블릿 폭 보기에서는 기존 학생 화면의 폭과 글씨를 사용한다.
- 단계 이동·화면 크기 버튼은 학생 화면의 스크롤 영역 밖에 배치한다. 안내 팝업은 학생 화면 영역 안에서만 표시한다.

## 검증

즉시 단계 이동, 실제 수업 변경 방지, 로컬 정책 제출과 뉴스 연결, 역할 공개, 성찰 기록 유지, 초기화와 지연 저장, PC·태블릿·전체 화면 전환을 회귀 테스트한다. 컴퓨터 브라우저에서도 팝업을 띄운 채 단계 이동과 넓은 카드 배치를 확인한다.
