# 정책과 뉴스 연결 수정 계획 — 2026-10-05

## 문제

공동 부담형 세금을 선택한 학생에게도 ‘고소득층 세부담 확대’ 뉴스가 표시될 수 있었다. 세금·예산·최저임금의 합산 성향으로 미리 정해진 뉴스 묶음을 가져오기 때문에, 다른 선택 조합에서도 개별 정책과 뉴스가 불일치했다.

## 수정 범위

1. 뉴스에 정책 분야와 선택지 조건을 부여하고, 실제 1차 정책에 맞는 카드만 제공한다.
2. 모든 정책 분야를 포함하면서 5장(긍정 2·경고 2·혼합 1)을 유지한다. 각 선택지에 세 종류의 상황을 준비하고, 한 분야에서 혼합 1장, 나머지 두 분야에서 각각 긍정·경고를 제공한다.
3. 공동 부담형과 능력 부담형의 차이를 세율 기준으로 설명하고, 뉴스는 가상의 토론 상황임을 화면에 명시한다.
4. 기존 성향 기반 카드·중복·누락·정책 불일치는 현재 정책에 맞게 교체한다. 유효한 저장 카드와 순서는 유지한다. 발표·미리보기·CSV에 같은 규칙을 적용한다.
5. 미리보기의 DB 쓰기를 차단하고, Firebase 트랜잭션의 초기 빈 캐시에서 가짜 세션을 생성하지 않도록 처리한다.
6. 자동 저장은 서버 완료 후 성공을 표시한다. 실패를 표시하고, 화면 이동 시 대기 중인 입력도 저장하며, 입력은 순서대로 저장한다.
7. README의 사용 주소·5단계·Firebase 동기화·설정·배포 안내를 갱신하고 CHANGELOG와 CI를 추가한다.

## 검증 기준

- 27가지 정책 조합에서 카드 5장이 모두 실제 선택과 맞고, 세 분야와 긍부정 균형을 만족한다.
- 공동 부담형 + 기본 보장형 + 생활 보장형에서 고소득층 세부담 확대를 가정하지 않는다.
- 불완전한 정책에 뉴스의 전제를 임의로 추가하지 않는다.
- 옛 세션을 열거나 CSV로 내보내도 정책에 맞는 내용이 나오고, 새 카드의 저장 순서는 보존된다.
- 미리보기는 DB에 쓰지 않고, 초기 빈 캐시는 실제 서버 값으로 재시도한다.
- 느린 저장·실패·단계 전환에서 자동 저장 상태와 마지막 입력을 확인한다.
- 테스트·정적 검사·프로덕션 빌드가 통과한 변경을 GitHub에 반영한다.

## 범위의 한계

전체 성향·안정도·격차의 기존 수업용 계산 체계는 유지한다. 실제 경제 예측 모델이나 교사·학생 인증 체계로 확장하는 작업은 이번 수정에 포함하지 않는다. 기존 세션의 카드 교체는 새 앱을 열었을 때 수행하며, 전체 DB를 일괄 변경하지 않는다.
