# 무지의 베일 — 정의로운 사회 만들기

롤스의 "무지의 베일" 사고실험을 체험하는 고등학교 사회 수업용 교실 시뮬레이션입니다. 모둠(2인 1팀)이 자신이 어떤 계층으로 태어날지 모르는 상태에서 사회 정책(세금·예산·최저임금)을 설계하고, 무작위로 정해진 역할을 통해 자신들이 만든 사회를 다시 검토합니다.

**데모: https://saam-kim.github.io/who-am-i-rebuild/**

## 화면 구성

- **학생 화면** (`/join`, `/play/:code`) — 아이패드 11인치 가로 기준. 참여 코드로 입장, 정책 설계, 역할 공개, 사건카드, 재설계, 발표, 성찰까지 6단계 진행.
- **교사 대시보드** (`/teacher`, `/teacher/:code`) — 세션 생성, 단계 진행·타이머 제어, 팀별 제출 현황, 룰렛 실행, 학생 화면 미리보기, CSV 내보내기.

## 로컬 실행

```bash
npm install
npm run dev
```

`http://localhost:5173`에서 교사 화면으로 세션을 만들고, 다른 탭에서 `/join`으로 입장해 실시간 연동을 확인할 수 있습니다.

## 동기화 방식

지금은 `localStorage` 기반 로컬 데모 모드입니다 — **같은 브라우저의 여러 탭 사이에서만** 동기화되고, 서로 다른 기기 간에는 아직 동기화되지 않습니다. 실제 교실에서 여러 기기가 동기화되려면 `src/store/sessionStore.ts`를 Firebase 등 실시간 백엔드로 교체하면 됩니다 — 스토어 인터페이스는 그 교체만으로 나머지 코드가 그대로 동작하도록 설계돼 있습니다.

## 기술 스택

Vite + React 19 + TypeScript + Tailwind CSS v4. GitHub Actions로 GitHub Pages에 자동 배포됩니다(`main` 브랜치 푸시 시).
